Titulo:  Producto Final Integrador Sistemas PAI - Programa Nacional de Inmunización 

Descripción:

    Construir una aplicación web moderna con NextJS, ShadCN, SupaBase
    Para El Ministerio de Salud y Deportes de Bolivia, a través del Programa Ampliado de Inmunización (PAI)
    Al tratarse de datos sensible el enfoque debe ser fijado en la segurdad de los datos
    Obligatorio la aplicacion debe estar en linea(Vercel, netlify,etc)

ejemplo base

https://github.com/FranklinRiabani/gestion-academica
